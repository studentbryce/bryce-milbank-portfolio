# Bryce Milbank Development

A personal developer portfolio showcasing my software development projects, technical skills, qualifications and CV.

Built with **HTML5, CSS3 and vanilla JavaScript**, with responsive layouts, animations and interactive project galleries.

## Featured projects

- **LensFlow** — Full-stack photography business management platform built with React, Node.js, Express and Supabase.
- **TestNest** — Multiple-choice testing platform with a React web app and React Native Android app sharing a Supabase backend.
- **Machine Learning** — Python and scikit-learn experiments comparing decision trees, clustering and neural networks.
- **Network Security** — Academic security assessment and T-Pot honeypot threat analysis project.

## Features

- Responsive desktop and mobile layout
- Light and dark themes
- Animated sections and interactive project filters
- Project case studies with screenshot galleries
- Downloadable PDF CV and contact information

## Run locally

1. Download or clone this repository.
2. Open `index.html` in your browser.

No installation or build process is required.

## Project structure

```text
index.html          Homepage
project.html        Project case-study pages
css/style.css       Styling and responsive layout
js/main.js          Website interactions
js/projects.js      Project details and galleries
assets/img/         Project screenshots and images
assets/docs/        PDF CV
```

## Deployment

This is a static website and can be hosted on **GitHub Pages** or **Vercel**. For GitHub Pages, publish the repository root containing `index.html`.
